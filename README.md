WEATHER FORECAST APP
====================

HOW TO RUN (WINDOWS)
1. Extract the project ZIP file.
2. Open the extracted Weather_Forecast_App folder.
3. Double-click START_APP.bat.
4. Your browser opens http://127.0.0.1:8000.
5. Keep the black command window open while using the app.
6. To stop the app, press CTRL+C in the command window.

REQUIREMENTS
- Windows 10 or Windows 11
- Python 3 installed and available as "py -3" or "python"
- Internet connection (weather data is retrieved online)

FEATURES
- Search weather by city name
- Automatically loads Chennai on startup
- Current temperature, feels-like temperature, humidity, wind speed,
  precipitation, weather description and local date/time
- No API key required

TROUBLESHOOTING
- If the browser says it cannot connect, check that the black command
  window is still open and showing the local server is running.
- If port 8000 is already in use, close the other local server and retry.
- If weather does not load, check your internet connection.
- If Python is not found, install Python 3 and enable Add Python to PATH.

Weather data: Open-Meteo (https://open-meteo.com/)
